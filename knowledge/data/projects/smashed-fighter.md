# Smashed Fighter

- Category: Video Games
- Type: multiplayer platform fighter
- Dates: 2022–ongoing
- Public URL: https://smashed.niemo.io
- Declared stack: Phaser, BrainJS, Aseprite, Express, MongoDB, FL Studio
- Platform: desktop web; keyboard and USB controllers

## What Eric built

Smashed Fighter is a platform fighting game and a long-running experimentation ground for game design and neural-network-controlled characters. The portfolio describes more than two years of work across gameplay, multiplayer, scripted bots, and learned bots. Players can fight with friends or watch bots battle one another.

Phaser provides the browser game layer; Aseprite supports pixel-art production; FL Studio supports original sound work; and the Express/MongoDB pieces indicate a server-backed web application. BrainJS is the declared neural-network library. The public data does not specify the exact network inputs, training data, or online synchronization model, so those details should not be guessed.

## Implementation and interaction details

The live project opens on a deliberately retro “START” screen. The published interface offers Play and Watch paths, matching the portfolio’s human-play and bot-spectator framing. It supports keyboard input and USB gamepads and is marked as a desktop experience rather than a mobile game.

## What it demonstrates

The project spans more than combat mechanics. It combines character control, animation, collision and physics, controllers, game-state orchestration, asset and audio creation, web services, persistent data, and AI opponents. It is one of Eric’s clearest examples of using a game environment as an ML laboratory while still producing a playable application.
