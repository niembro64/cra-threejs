# Tanks & Gates

- Category: Video Games
- Type: free-roam shooter
- Date: 2024
- Public URL: https://games.niemo.io/tanks
- Declared stack: Phaser, React, FL Studio
- Platforms: desktop and mobile web; desktop is the recommended experience

## What Eric built

Tanks & Gates is a free-roaming tank shooter organized around an unusual projectile mechanic. Bullets interact with different gates that can mirror, transmit, refract, or multiply them. The gates turn aim into a geometry problem: a shot can be redirected, duplicated, or carried through space rather than traveling only in a straight line.

The game supports desktop mouse and keyboard controls and two-thumb mobile controls. It includes sound and lists FL Studio in its production stack.

## Published experience observed August 13, 2026

The live page identifies itself as “Tanks Runner” on its start screen and exposes several demo or presentation controls, including color and zoom variations. The deployed title therefore differs slightly from the “Tanks & Gates” name used on niemo.io. The canonical portfolio video shows the gate-based combat concept; the start screen alone does not document every gate rule or game objective.

## What it demonstrates

The project combines top-down movement, aiming, projectile physics, collision and transformation rules, camera behavior, responsive dual-input design, Phaser gameplay, React integration, and audio production. The gate system is the main design experiment: a small set of consistent transformations can produce richer tactical behavior than adding more ordinary weapon types.
