# CSS Experiments

- Category: Full-Stack Web / Design
- Type: web styling and interaction experiments
- Date: 2022
- Public URL: https://design.niemo.io
- Declared stack: vanilla HTML, CSS, and JavaScript
- Primary platform: desktop web

## What Eric built

CSS Experiments is a collection of small original interactions, mini-games, and playful studies created with foundational browser technologies. It avoids a framework so that layout, transforms, hover states, event handling, selection behavior, sound effects, and visual feedback are expressed directly in HTML, CSS, and JavaScript.

## Published experience observed August 13, 2026

The live page explicitly says it is meant for desktop. Visible experiments include Cube Twist, which changes a cube through hover and click; Glass Hunt, a target-and-score interaction; Menu Slip, an animated menu; Card Grab; Pixel Play, an RGBA color modifier; CheckBox Tweak, which counts selections; and in-progress LoadBar Fill and Form Shape pieces. The site labels the content as vanilla HTML/CSS/JS.

These are individual sketches rather than one business application. They explore cards moving around, click and hover behavior, selections, small game-like goals, and synchronized sound or visual responses. Their purpose is to isolate an interaction or visual technique, making each behavior easy to manipulate and inspect.

## What it demonstrates

The collection shows comfort with browser primitives: 2D and 3D CSS transforms, hover and pointer states, transitions, generated visual elements, color channels, form controls, sound effects, selection state, layout, and direct DOM events. It also documents Eric’s design sensibility and willingness to explore small interface ideas without requiring a larger product justification.
