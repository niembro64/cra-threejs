# niemo.io frontend sources

These files are snapshots of the public structured data that drives the niemo.io frontend. They were copied from `src/data/` and `src/config/` so the résumé voice agent can ground answers in the same project and portfolio data shown by the site.

The generated `knowledge/niemo-io-resume.md` document is the compact, human-readable canonical summary. The source snapshots remain available for details that are not included in that summary.
